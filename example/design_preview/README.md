## Gamepad demo

Open **Widgets → Gamepads** (`/widgets/gamepads`) to try Xbox, PS5, and Switch Pro
views from `duskmoon_widgets`. Each model has live stick coordinates, trigger
percentages, and button feedback. Hold Xbox/PS5 triggers to increase and release
to decrease at one full range per second. Each supported model has its own
trigger-indicator toggle; Switch Pro triggers remain digital.

The golden tests use `chart-cjk.otf` for the shared fixture's Chinese category
label. It is a fontTools subset of face 2 (Simplified Chinese) from Noto Sans
CJK Sans 2.004, containing only the characters in `某个非常长的重复分类标题`.
The source is [Noto CJK Sans 2.004](https://github.com/notofonts/noto-cjk/releases/tag/Sans2.004).
